# Developer Workplace hand-drawn redesign

Implemented October 4, 2026. Visual reference: `C:/ai-tool/design/hand-drawn-design.txt`. Presentation changes preserve the existing routes, modular workspace, authentication, authorization, schemas, AI request logic, data models, and persistence handlers. No deployment was performed.

1. **Previous issues:** Uniform rounded boxes, soft gradients, inconsistent handwritten headings, pale text on light toolbar surfaces, and a dark theme that retained bright cream sheets. The portfolio lacked the notebook accents already present in parts of the workspace.
2. **Direction:** An orderly developer notebook with warm paper, dark sketchbook surfaces, marker emphasis, restrained scribbles, and readable technical content.
3. **Tokens:** Added `--font-hand`, `--radius-sheet`, `--radius-note`, `--sketch-edge`, `--sketch-shadow`, `--marker`, and `--marker-ink`. Reused existing spacing, surface, status, accent, and panel-width tokens and layout rules.
4. **Typography:** Existing Caveat for major headings, signature, timeline dates, and timer; existing Manrope/body UI typography for navigation, task titles, forms, messages, and technical prose. No additional font families.
5. **Colors:** Parchment and warm charcoal with ochre primary actions, dusty blue, lavender, sage, and clay accents. Semantic status colors remain labeled.
6. **Treatments:** Asymmetric elliptical corners, offset pencil shadows, wavy title accents, marker highlights, clipped tape, sketch arrows, and double-stroke underlines. Interactive grids and draggable elements receive no decorative rotation.
7. **Activity rail:** Preserved destinations and responsive bottom navigation. Active items use a loosely drawn oval; the brand has an irregular outlined edge.
8. **Context sidebar:** Paper margin treatment, handwritten section heading, readable controls and helper copy. Resize handle stays eight pixels wide and now sits inside the panel to avoid a horizontal sidebar scrollbar.
9. **Tabs:** Existing document tabs receive notebook corners and a marker active edge. Existing select/close handlers remain.
10. **Main workspace:** Shared paper and dark-paper components receive consistent sketch edges. The existing grid, sections, density, and modular structure remain.
11. **Buttons/forms:** Ochre marker primary buttons; outlined paper secondary actions; readable input text, restrained irregular corners, and visible pencil focus outlines. Existing destructive actions retain their status colors.
12. **Dialogs:** The floating inner sheet receives the sketch treatment; the transparent native dialog overlay and its focus/escape behavior remain. Task and project editor dialogs were opened and closed without saving.
13. **Task Kanban:** Sticky-note edges, compact readable metadata, pastel status icons, dashed dividers, and unchanged board scrolling, column widths, DnD sensors, and persistence logic. Light toolbar contrast corrected. Pure move/reopen/order regressions pass.
14. **Project Kanban:** More substantial cards with lavender margin strokes and handwritten workflow headings. Existing project ordering and status behavior are unchanged; live board rendered in both themes.
15. **Calendar:** Precise seven-column grid, square date cells, visible dark-paper grid borders, sketch page border, handwritten month, and irregular selected-date marker. Existing reschedule and timezone tests pass. Screenshots captured at all five requested widths in both themes.
16. **Focus Mode:** Existing panel hide/restore behavior verified by entering and exiting in the browser. No new animation.
17. **Focus Session:** Readable Caveat numeric display with tabular numerals. Live start, pause, resume, and end verified; countdown and timestamp regression tests pass. Test session ended.
18. **Workspace AI:** Existing desktop dock/mobile sheet and launcher retained. Paper-note bubbles, readable message body, and context chips differentiated by icon, type text, and pastel color. Open/minimize and keyboard resizing verified. No provider request or upload sent during review.
19. **Public portfolio:** Shared visual family without the private IDE structure; existing public data filtering, navigation, content, and contact gates preserved.
20. **Hero:** Large handwritten name, highlighted professional headline, small arrow annotation, scribble underline, framed portrait, and clearly differentiated project CTA.
21. **Experience:** Dashed notebook timeline, handwritten dates, and clean system/role descriptions. Resume-aligned content unchanged.
22. **Skills:** Existing grouped skills retained; handwritten category headings with readable item lists. Compact core stack chips use irregular corners.
23. **Project cards:** Clay marker top edge, underlined title, rough screenshot frame, restrained hover shadow, and existing case-study/demo/repository links.
24. **Case studies:** Existing published sections and gallery use the shared notebook styling. No invented project facts or new data fields. Missing optional published sections remain omitted.
25. **Public AI:** Existing launcher/popup retained; matching paper-note messages and suggestion notes. Disclosure and public-only boundary remain visible. Both desktop themes and a narrow mobile popup reviewed.
26. **Resume CTA:** Fixed PDF download href and download attribute preserved. Rendering regression passes; a real browser download completed successfully to `C:/Users/Franz/Downloads/Franz_Michael_Cayanan_Resume.pdf`.
27. **Light mode:** Warm cream surfaces and dark ink; contrasting dark work panels remain part of the existing workspace design. Toolbar and Kanban copy use their correct surface ink.
28. **Dark mode:** Cream-family tokens now resolve to warm charcoal paper with cream text. Portfolio surfaces, images, outlines, and secondary links are deliberately themed; pastel primary labels retain dark ink.
29. **Mobile:** Portfolio and private Task Kanban examined at 1440, 1024, 768, 390, and 320px in both themes. Document scroll width never exceeded viewport width. Header actions wrap, hero arrow is removed on small screens, and decorative card rotations are disabled. Mobile drawer and AI sheet opened successfully.
30. **Accessibility:** Native semantics, focus outlines, status labels, icon labels, and existing dialog behavior retained. Decorative SVGs are `aria-hidden`, non-focusable, and ignore pointer events. Context chips include icons and type text. Automated contrast/screen-reader audit was not performed.
31. **Performance:** CSS and one small inline SVG component; no dependencies, animation libraries, canvas backgrounds, giant illustrations, or new remote assets. Existing Google font loading remains.
